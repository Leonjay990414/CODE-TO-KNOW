# 碼上學｜CODE TO KNOW

**品牌全名：** 碼上學 AI 智慧學習與教育科技平台

**英文標語：** Learn Beyond Limits.

**品牌標語：** 碼上學，學無止境。

## 專案簡介

碼上學是一個以 AI 技術為輔助的智慧教育科技平台，
致力於整合課程、學習資源、練習、測驗及互動式學習體驗。

平台以培養自主思考與理解能力為核心，
讓 AI 成為學習輔助工具，而不是取代學習者思考。

## 專案目標

建立支援電腦、平板及手機的跨裝置教育平台。

## 專案狀態

目前處於品牌建立與專案基礎建置階段。

## 開發環境

- Antigravity IDE
- Node.js
- npm
- Git
- GitHub

## 重要原則

- 重視使用者資料與系統安全。
- AI 協助學習，不取代獨立思考。
- 採用模組化及可擴充的系統架構。
- 重視使用體驗與跨裝置支援。
