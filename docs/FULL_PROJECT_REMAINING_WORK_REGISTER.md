## 三、技術債與未解決問題登錄 (Technical Debt Register)

1. **TD-01：L4/L5 資料庫角色未物理分離**
   - **現況：** 資料庫僅有 `STUDENT`、`TEACHER`、`ADMIN`，System Ops 暫時由 `ADMIN` 授權保護。
   - **解決路徑：** 待獲准執行 Migration 時，於 Prisma Schema 之 `Role` 表增加 `PLATFORM_ADMIN` 與 `SYSTEM_OPERATOR`。
2. **TD-02：官方郵件域名無 MX 伺服器**
   - **現況：** 寄往 `contact@codetoknow.edu.tw` 會退信。
   - **解決路徑：** 申請 Cloudflare / Google Workspace 企業郵箱並綁定 DNS 紀錄。
3. **TD-03：前端靜態頁面目錄待完全解耦**
   - **現況：** 27 個頁面有 21 個置於 `pages/public/`，其餘在子目錄，29 處元件匯入有耦合。
   - **解決路徑：** 在後續重構階段分批搬移至 `marketing/`, `student/`, `teacher/`, `platform-admin/`, `system-ops/` 並設定路徑別名。
4. **TD-04：雲端 APM 探針缺位**
   - **現況：** System Ops 頁面的 CPU/RAM 指標標註「尚未介接 APM」。
   - **解決路徑：** 於 Render 或雲端主機安裝 Datadog 或 Prometheus Node Exporter 探針。
