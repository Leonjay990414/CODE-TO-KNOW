## 一、專案身分與核心理念 (Project Identity & Mission)

### 1. 品牌基本資料
- **中文品牌：** 碼上學
- **英文品牌：** CODE TO KNOW
- **品牌全名：** 碼上學 AI 智慧學習與教育科技平台
- **中文標語 (Slogan)：** 碼上學，學無止境。
- **英文標語 (Tagline)：** Learn Beyond Limits.
- **官方網站 (Production)：** `https://code-to-know-web.onrender.com/`
- **GitHub 儲存庫：** `Leonjay990414/CODE-TO-KNOW`
- **歷史隔離承諾：** 本專案為獨立新專案，完全杜絕與歷史專案（如 CodeSolv）混淆。

### 2. 平台核心使命
打造一個結合「學術理論、技術實務、證照考題、AI 啟發教學、教育遊戲與師生協同管理」的一體化現代教育科技平台。
- **教育核心理念：** **AI 應當啟發獨立思考，而非取代獨立思考。**
- **防作弊與劇透原則：** 平台嚴格禁止直接提供完整程式碼解答，全面導入四階段蘇格拉底式認知鷹架引導（理解題意 → 破題思路 → 邊界提點 → 架構解構）。

## 二、全站五層系統架構 (Five-Layer Architecture)

專案嚴格依循五層網站架構劃分權責、介面與存取權限：

| 層級代號 | 系統層級名稱 | 目標受眾與角色 | 核心功能範疇與責任邊界 | 主要入口與路由 |
| :---: | :--- | :--- | :--- | :--- |
| **L1** | **公開品牌網站** | 所有訪客、潛在學員、家長 | 品牌定位展示、教育理念、特色體驗展示、會員註冊與登入導流、法律條款與隱私聲明。 | `#hero`, `#story`, `#experience`, `#privacy` |
| **L2** | **學生學習平台** | 學生會員 (`STUDENT`) | 605 題官方學科題庫測驗、全真模擬考、術科五大題組學習與沙箱練習、AI 教學教練、個人學習歷程與弱點分析、五大教育互動遊戲。 | `#theory`, `#mock-exam`, `#practical`, `#games`, `#ai-coach`, `#progress` |
| **L3** | **教師教學後台** | 認證教師 (`TEACHER`) | 班級建立與管理、8 碼加入碼發放、學生名冊檢視、移除學員、遊戲化作業指派 (`P14-GAM-014` 展示原型)、學情診斷。 | `#teacher` |
| **L4** | **平台管理後台** | 平台管理員 (`ADMIN`) | 教師身分資格審查（核准/拒絕）、全站資安 Audit Log 稽核日誌檢視、遊戲全域難度/時間/容差參數調控 (`P14-GAM-015` 本機原型)。 | `#admin` |
| **L5** | **系統營運後台** | 系統營運員 (`SYSTEM_OPERATOR` / `ADMIN`) | 系統健康狀態、PostgreSQL 連線延遲檢測、API 流量率限制狀態、快取機制監控、維護模式與服務開關。 | `#system-ops` |
| **Shared**| **共用核心元件** | 全角色通用 | 頂部全域導覽列 (`Navbar`)、頁尾與法律連結 (`Footer`)、身分驗證彈窗 (`AuthModal`)、通知中心 (`NotificationCenterModal`)、回饋系統 (`FeedbackModal`)。 | 全站共用 |

## 五、專案實體規模與代碼資產統計 (Physical Metrics)

- **前端頁面總數：** 27 個頁面元件（`pages/public/` 21 個、`pages/student/practical/` 5 個、`pages/system-ops/` 1 個）。
- **前端工具模組 (Utils)：** 19 個純 TypeScript 工具庫（涵蓋遊戲儲存、防刷節流、每日任務、AI 安全過濾、代碼 Linter、錯題本、弱點分析、UTM 解析等）。
- **後端 API 路由與控制器：** 4 大核心業務模組（Auth、Teachers、Admin、Classrooms）共 16 支 RESTful API 端點，配置嚴格 Zod Schema 驗證與 CSRF/RateLimit 防護。
- **資料庫架構：** 33 個 Prisma Models、1 個 Enum、2 個標準關聯遷移腳本 (`migrations`)。
- **全站自動化測試：** **58 個測試檔案，共 620 項測試全數 100% 通過**（前端 41 檔案 399 測試，後端離線 17 檔案 221 測試）。
- **生產編譯狀態：** `tsc --noEmit` 0 錯誤；`npm run build --prefix frontend` 耗時 2.35 秒順利完成。
