## 二、標準解答實際運作與架構分析

### 1. 標準解答首頁運作表現
- **尺寸與佈局**：整體寬度為 `1024px`，高度設定為 `calc(768px - 65px - 20px)`，透過 `margin: auto` 實現水平置中，完全契合官方試題圖 1-2 規範。
- **導覽連動機制**：
  - 首頁選單的「吉他社」超連結設定 `target="myFrame"`，精確將子頁導向右下方的 `iframe` 容器內。
  - 各子頁面（如 `guitar_history.html`）中的「回社團介紹首頁」按鈕明確宣告 `target="_top"`，完全防止發生「巢狀內嵌（iframe 塞進 iframe）」的致命 0 分考場陷阱。
- **CSS 技巧特點**：
  - 選單按鈕採用背景圖片切換技術：預設為 `menu1.png`，懸停時觸發 `.menu:hover { background-image: url('../images/menu2.png'); }`，無須 JavaScript 即可滿足動態變色要求。
  - 使用 `calc(100% - 215px)` 與 `calc(100% - 25px)` 計算右欄與左欄高度，避免固定像素在不同環境下換行。

### 2. 老師教學網系統的創新功能（亮點分析）
- **互動式版型架構導覽圖（Layout Diagram）**：
  在首頁將 1024×768 的切版規格視覺化為 7 個彩色區塊，並於每個區塊綁定點擊事件，學生點選「選單區」即可直達步驟三教學，直觀掌握空間概念。
- **圖文與影音雙軌教學（Web Speech API + MP4/YouTube）**：
  利用瀏覽器原生的 `window.speechSynthesis`（Web Speech API），在無後端音訊檔的情況下，自動逐字朗讀解題腳本（支援 0.85x 至 1.4x 語速調節），同時提供本機影片選擇器與 YouTube 嵌入器。
- **線上實作與自動評分檢核（Practice Sandbox）**：
  內建「填空挑戰」與「標準範本」，學生於 textarea 輸入程式碼後，即時利用正則表達式（Regex Checkers）檢核是否有設置 `margin: auto`、`target="myFrame"`、`marquee` 等必備考點，立即給出通過/未通過判定。
- **35 項考前全真檢核表（LocalStorage 勾選連動）**：
  涵蓋檔案命名、目錄階層、版面尺寸、文字錯漏字、連結 target、影像合成尺寸等考場關鍵扣分點，自動儲存於瀏覽器。

## 五、分類處置清單（保留、優化、新增、重新設計、不採用）

### 1. 【保留】完全不需要修改之功能
1. **React + TypeScript + Vite 核心架構**：完全保留，不改動技術堆疊。
2. **多使用者與進度隔離儲存引擎 (`learningStorage.ts`)**：支援 Guest、Student、Teacher 權限與本機隔離，品質優良。
3. **題組五大分頁選擇與權限流程**：維持現有頂端麵包屑、難度標籤與切換邏輯。
4. **全站品牌視覺規範與 Design Tokens**：沿用溫潤象牙白、霧面藍灰、香檳金與深石墨色系，不採用老師答案中較傳統的高飽和色彩（如 `#FF00FF`、`#0000FF`）。

### 2. 【優化】現有功能已存在，但可吸收老師優點
1. **分步教學內容深度 (`unifiedPracticalCurriculumData.ts`)**：
   - 吸收老師 `learning-data.js` 中的實戰代碼片段、排錯口訣與驗收標準，豐富現有步驟的說明文字。

   - 將現有 4 項基礎檢核點擴充為老師精煉的 35 項全真查核項目（涵蓋：環境建立、首頁尺寸、切版佈局、主標題區、跑馬燈、選單按鈕、日期更新、內容頁 iframe、子頁面錨點、頁尾版權）。
3. **Version B 影音實戰教學介面**：
   - 在 Version B 頁面補齊影音播放容器（支援 YouTube 嵌入與本機影片播放）。

### 3. 【新增】CODE TO KNOW 尚未提供且具高度價值之功能
1. **互動式版型架構導覽圖元件 (`InteractiveLayoutDiagram.tsx`)**：
   - 於題組一版面規格區塊下方，新增 1024×768 比例的互動導覽圖，點擊頂部跳轉步驟三、點擊選單跳轉步驟五、點擊內容區跳轉步驟四/六/七。
2. **標準解答完成品即時預覽體驗元件 (`StandardAnswerPreview.tsx`)**：
   - 整合標準答案的靜態產物，提供 1024×768 預覽視窗與 5 大子頁面快速切換按鈕，讓學生實作前先體驗成果。
3. **Web Speech API 智慧語音導覽助手**：
   - 支援國語語音逐段朗讀步驟重點，降低學生閱讀大量文字的疲勞感，支援語速切換與即時暫停。
4. **題組一隨堂實作觀念測驗模組 (`TaskQuizSection.tsx`)**：
   - 內建 15 題考點快問快答（如：`target` 屬性設定、1024 置中技巧、跑馬燈方向與字型規定）。

### 4. 【重新設計】雙方均有不足之功能
1. **步驟及時練習與評分機制**：
   - **老師不足**：僅使用陽春的 `<textarea>`，無語法高亮、排版易混亂。

### 5. 【不採用】不符合平台定位之項目
1. **多檔案傳統 HTML 靜態跳轉架構 (`step1.html` ~ `step7.html`)**：不採用，CODE TO KNOW 採 SPA 單頁應用架構，維持平滑狀態切換。
2. **高飽和度傳統色彩樣式**：不採用老師版面中使用的 `#fef3c7`、`#fae8ff`、`#dbeafe` 混雜色塊，統一轉換為 CODE TO KNOW 的 Misty Blue Gray 與 Warm Ivory 高級教育品牌色。
3. **直接將外部影片檔案打包進專案儲存庫**：不採用（防範專案龐大膨脹與版權爭議），影音串流採外鏈或本地自定義載入機制。
