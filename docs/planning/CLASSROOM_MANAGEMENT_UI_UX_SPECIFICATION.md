## 一、設計願景與品牌調性定位

### 1.1 品牌視覺規範依據（Brand Palette Alignment）
班級管理系統完全遵循《CODE TO KNOW 品牌設計規範》與色票系統，營造出專注、典雅且專業的現代教育科技體驗：
- **底色背景（Warm Ivory）**：`#F5F2EA`，柔和溫暖，降低長時閱卷視覺疲勞。
- **主導強調整（Champagne Gold）**：`#BDA77E`，呈現高雅且關鍵的動作指引（CTA、重點標籤）。
- **結構與次要強調（Muted Blue Gray / Misty Blue Gray）**：`#8FA9B8` 與 `#D9E2EA`，用於側邊欄、分隔線、資訊卡片底色與未選中狀態。
- **文字與對比（Slate Dark / Charcoal）**：`#1E293B`（主標題）與 `#475569`（內文說明），確保符合 WCAG 2.1 AA 高對比標準（$\ge 4.5:1$）。
- **字型規範**：
  - 繁體中文：`Noto Sans TC`, system-ui, sans-serif
  - 英文與數字符號：`Inter`, monospace（代碼呈現）

## 二、多裝置響應式斷點與排版策略（Responsive Breakpoints）

系統針對行動端、平板與高解析度桌機提供一致且順暢的排版流動（Fluid Typography & Flex/Grid Layout）：

| 裝置類型 | 螢幕寬度 ($W$) | 班級卡片佈局 | 學生名冊表格佈局 | 導覽與操作列行為 |
| :--- | :---: | :---: | :---: | :--- |

```
|  | 邀請碼: 7K9M3X2P [複製]|  | 邀請碼: 4W8N9Y6D [複製]|  | (已結束選課)       |  |

```

#### A. 零資料狀態（Zero Data / Empty State）
- **呈現原則**：嚴禁展示假學生姓名或假班級卡片。
- **元件視覺**：
  - 居中展示灰階細緻插圖（書本與黑板線條圖標）。
  - 主標題：「尚未建立任何教學班級」。
  - 副說明：「您可以立即建立專屬班級，系統將自動產生 8 位邀請碼，讓學生即刻掃描或輸入加入。」
  - 核心動作按鈕：香檳金按鈕 `[立即建立第一個班級]`。

#### B. 邀請碼展示卡片（Join Code Hero Card）
- 放大等寬字型顯示（`font-mono font-bold tracking-widest text-2xl`），字元間距擴大。
- 點擊按鈕直接調用 `navigator.clipboard.writeText()`，並彈出微型綠色 Toast：「邀請碼已複製至剪貼簿」。
- 點擊「顯示 QR Code」彈出 Modal，高對比度黑白二維條碼便於投影幕遠端掃描。

### 3.2 學生端加入班級互動（Student Join Modal）

```
+-----------------------------------------------------+
|  加入教學班級                                 [X]   |
+-----------------------------------------------------+
|  請輸入指導教師提供的 8 碼班級邀請碼：              |
|                                                     |
|      +---+---+---+---+ - +---+---+---+---+          |
|      | 7 | K | 9 | M |   | 3 | X | 2 | P |          |
|      +---+---+---+---+ - +---+---+---+---+          |
|                                                     |
|  提示：代碼不區分大小寫，系統已自動排除易混淆字元。  |
|                                                     |
|  [ 取消 ]                          [ 確認加入班級 ] |
+-----------------------------------------------------+
```

#### 互動微體驗（Micro-interactions）：
1. **分段輸入格（Segmented Input）**：提供 8 格獨立框或單一自動大寫、自動過濾非法字元（如輸入 0 自動提示或防呆）之輸入框。
2. **即時檢驗**：滿 8 碼時自動觸發格式校驗，邊框轉為溫潤金黃光暈；未滿 8 碼時按鈕維持 Disabled 狀態。
3. **載入動畫（Loading State）**：按下按鈕後轉為旋轉 Loader，防止學生重複點擊。

### 3.3 班級學生名冊與進度檢視（Student Roster Table）

#### 欄位與排版結構：
1. **勾選框（Checkbox）**：支援全選與批次匯出。
2. **座號/學號**：`#475569` 等寬對齊。
3. **學生姓名與頭像**：展示圓形首字縮寫頭像與全名。
4. **學科進度條（Academic Progress Bar）**：
   - 雙層進度條：完成題數百分比（底色 `#E2E8F0`，填滿色 `#8FA9B8`），旁側標注「580/605 (95%)」。
5. **術科達標徽章（Practical Badges）**：
   - 依序展示 104301 至 104305 五個圓形狀態燈號（綠色：已通過、黃色：進行中、灰色：未開始）。
6. **最後活動時間**：相對時間標記（例如：「10 分鐘前」或「2 天前」）。
7. **操作區**：點擊彈出動作下拉選單（`個別成績報表`、`診斷建議`、`自班級移除`）。

## 四、無障礙規範與鍵盤無障礙支援（WCAG 2.1 AA Compliance）

1. **色彩對比度**：
   - 所有本文文字對背景之對比度嚴格保持在 $4.8:1$ 以上。
   - 所有互動元件外框在 Focus 狀態下呈現 `2px solid #BDA77E` 高對比光環，且具備 `2px offset`。
2. **ARIA 語意標記**：
   - 班級列表容器：`role="region" aria-label="教學班級清單"`。
   - 邀請碼展示區：`aria-live="polite"`，複製成功後螢幕閱讀器發報語音：「班級代碼 7K9M3X2P 已複製」。
   - 學生名冊表格：使用標準 `<table>`、`<thead>`、`<th>`（標註 `scope="col"`）與 `<tbody>`。
3. **鍵盤完整巡覽（Keyboard Traversal）**：
   - `Tab` 鍵循序聚焦於各卡片核心操作鈕；`Enter` / `Space` 鍵可啟動對話框或展開名冊。
   - Modal 彈出時實施**焦點鎖定（Focus Trap）**，關閉後焦點返回觸發元素。
   - 支援 `Escape` 鍵即時關閉所有彈窗與下拉選單。
