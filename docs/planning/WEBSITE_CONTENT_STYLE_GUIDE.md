# CODE TO KNOW｜網站文案風格與內容品質規範 (WEBSITE CONTENT STYLE GUIDE)

- **品牌中文**：碼上學
- **品牌英文**：CODE TO KNOW
- **完整全名**：碼上學 AI 智慧學習與教育科技平台
- **品牌標語**：碼上學，學無止境。 (Learn Beyond Limits.)
- **文件版本**：v1.0 (2026-11-14)

---

## 一、品牌核心語氣 (Brand Voice)

1. **專業但不冷漠 (Professional & Approachable)**：
   - 作為教育科技平台，用詞精準且經得起國家檢定標準檢驗。
   - 語氣溫和且具鼓勵性，不使用高高在上的批判口吻。
2. **啟發思考而非直接給答案 (Scaffolding Mindset)**：
   - 秉持「AI 鷹架分階導引」的核心使命，提示應引導學生自主推導邏輯，而非廉價直接拋出整段解答。
3. **沉穩誠實，不誇大未就緒功能 (Honest & Grounded)**：
   - 示範階段明確標示 `✦ 前端展示示範資料庫 (Demo Data)`。
   - 未連接後端之功能（如雲端即時同步、正式班級申請）嚴禁宣稱已上線，明確向使用者說明目前狀態與後續連動規劃。

---

## 二、用詞規範 (Terminology & Locale)

1. **正體中文 (繁體中文) 與台灣在地常用詞**：
   - 採用「程式設計 / 程式碼」，不使用「編程 / 代碼」。
   - 採用「專案 / 題組 / 考科」，不使用「項目 / 項目組」。
   - 採用「軟體 / 資訊科技」，不使用「軟件 / 資訊技術」。
   - 採用「介面 / 視窗 / 畫布」，不使用「界面 / 窗體」。
   - 採用「模擬測驗 / 模擬考」，不使用「模擬試題刷題」。
2. **技能檢定精準官方稱謂**：
   - 「勞動部勞動力發展署技能檢定中心」
   - 「17300 網頁設計 丙級」
   - 「學科測試（80 題單選）」與「術科測試（五大題組版面實作）」
   - 嚴格區分「官方評分標準」與「平台輔助判定規則」。

---

## 三、標題與按鈕命名規範 (Action & Navigation)

1. **按鈕命名原則 (Verb + Noun)**：
   - 動詞優先、簡短有力、不可產生歧義。
   - 正向動作：「開始探索平台」、「進入證照中心」、「開始模擬測驗」、「執行即時預覽」。
   - 次要/重設動作：「重設骨架」、「清除篩選條件」、「重新作答」。
2. **防墜行與孤字防護**：
   - 主要行動按鈕統一套用 `.btn-nowrap`，禁止因響應式斷點使最後一個中文字孤立墜至下一行（如「戰」、「練」）。

---

## 四、操作提示與空狀態 (Feedback & Empty States)

1. **空狀態 (Empty State)**：
   - 必須清楚告知「目前沒有找到什麼」以及「下一步可以怎麼做」。
   - 例：「查無相符的證照檢定項目：沒有找到與關鍵字相符的證照，建議您放寬關鍵字或清除篩選條件。」
2. **錯誤提示 (Error Handling)**：
   - 指出原因、提供處理方案。
   - 不得只顯示技術代碼（如「Error 500」），應轉換為「資料讀取異常，已為您自動載入預設安全狀態」。
3. **成功與結算回饋 (Success & Celebrations)**：
   - 明確回報完成的成果與指標（如「恭喜完成模擬考！總分 85 分，已安全達到及格標準」）。
