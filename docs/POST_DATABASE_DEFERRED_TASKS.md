## 追蹤原則

1. **不可覆蓋原則**：任何後續任務若未獲得明確授權，不得逕自刪除本清單內之列管項目。
2. **真實標記原則**：只有在後端資料庫、API、前端介面與端對端測試皆驗收通過時，始得將項目改為 `DONE`。
3. **安全第一原則**：涉及身分安全、資料隔離與個資外洩之項目（DEF-01 至 DEF-04），列為正式資料庫施工完成後之最高優先處理級別。
