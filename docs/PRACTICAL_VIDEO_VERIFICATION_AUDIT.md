## 一、稽核目標與嚴格查證準則

### 1. 稽核目標
本階段稽核旨在針對目前專案中所有涉及「五大術科影音教學研究」的文檔進行嚴格的實質證據檢驗。杜絕將「搜尋摘要」、「考綱推論」、「民間通用口訣」或「標題猜測」包裝為「已觀看紀錄」，確保專案的每一項技術教學均建立在 100% 誠實、可追溯且經過交叉核實的事實基礎之上。

### 2. 嚴格分類狀態定義（規範要求）
依據專案規範，所有影片之研究狀態嚴格限用以下五類，不得混淆：
- **`VERIFIED_WATCHED`**：已透過影音串流實際逐幀/逐秒觀看，完成詳細操作手勢與內容紀錄。
- **`VERIFIED_TRANSCRIPT`**：已取得可核實之官方/自動字幕（SRT/VTT）逐字稿，但尚未完成實際畫面觀看。
- **`PARTIAL`**：已完成部分外圍研究（如播放清單對應、考綱題組配比、核心功能映射），但未取得完整內容。
- **`BLOCKED`**：因環境無串流播放器、無外部字幕 API 或網路權限限制，目前技術上無法直接取得影音內容。
- **`NOT_STARTED`**：尚未啟動任何研究。

> [!CAUTION]
> **鐵律遵循**：
> 1. 嚴禁將 `VERIFIED_TRANSCRIPT` 或 `PARTIAL` 標記為 `VERIFIED_WATCHED`。
> 2. 嚴禁在未取得逐字稿或實體影音畫面時，自行編造「老師在影片中說了什麼」或捏造時間戳記（Timestamps）。
