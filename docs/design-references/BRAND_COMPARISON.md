# 碼上學｜CODE TO KNOW

# 國際品牌設計系統比較研究

> 文件用途：UI/UX 設計研究與視覺方向參考  
> 研究品牌：Apple、Nike、Linear、Stripe、Notion  
> 專案品牌：碼上學 AI 智慧學習與教育科技平台  
> 原則：研究設計方法，不複製品牌識別、商標或獨特版面。

---

## 1. 研究目的

本文件整理五個國際品牌的設計特色，從色彩、字體、排版、元件、間距與動效等面向進行比較，作為「碼上學｜CODE TO KNOW」後續 UI/UX 設計的參考。

本研究並非要複製任何單一品牌，而是分析不同品牌如何透過視覺設計建立辨識度、專業感與使用體驗，再將適合的設計原則轉化為碼上學自己的設計語言。

## 3. 五大品牌比較

### 3.1 Apple

**設計印象：** 簡潔、精緻、產品導向。

可研究的方向：

- 以留白建立視覺層次。
- 讓產品或核心內容成為畫面主角。
- 使用清楚的標題與內文層級。
- 避免過多裝飾干擾資訊閱讀。
- 維持整體頁面的一致性。

碼上學的應用：

- 首頁主視覺與品牌介紹。
- 課程與學習功能的展示方式。
- 重要資訊的層級與留白。

資料限制：目前專案保存的 Apple README 僅提供外部資料指向，尚未取得完整原始設計系統。

### 3.2 Nike

**設計印象：** 強烈、動態、具有品牌張力。

參考文件呈現的特色：

- 黑、白、灰為主要介面色彩。
- 大型標題搭配強烈的字級對比。
- 使用大型活動影像作為視覺主角。
- 主要操作按鈕採膠囊形狀。
- 間距採用以 8px 為基礎的尺度。
- 商品與內容影像本身承擔主要視覺表現。

碼上學的應用：

- 首頁大型標題與主視覺構圖。
- 重要學習活動的宣傳區塊。
- 適度運用動態呈現，增加網站活力。

不採用的部分：

- 不直接改成 Nike 的黑白品牌配色。
- 不複製其活動頁面、標誌或影像配置。

### 3.3 Linear

**設計印象：** 專業、精準、科技感。

參考文件呈現的特色：

- 深色背景搭配淺色文字。
- 以單一紫藍色作為主要強調色。
- 使用細緻邊框與深色面板。
- 標題字體具有明顯的字距控制。
- 元件圓角相對克制。
- 資訊密度較高，但仍維持清楚的層級。

碼上學的應用：

- 學生學習儀表板。
- 教師管理後台。
- 題目作答與學習紀錄介面。
- AI 助教的操作狀態與提示層級。

不採用的部分：

- 不直接將整個碼上學改成深色介面。
- 不將 Linear 的紫藍色作為品牌主色。

### 3.4 Stripe

**設計印象：** 專業、可信任、資料導向。

參考文件呈現的特色：

- 白色背景搭配深藍文字。
- 使用靛藍色作為重要操作強調。
- 以漸層網格作為部分行銷主視覺。
- 重視數字、表格與資料的可讀性。
- 使用儀表板與產品介面展示服務內容。
- 以膠囊形按鈕建立明確的操作層級。

碼上學的應用：

- 學習成效與弱點分析。
- 成績、答題時間與學習紀錄。
- 教師班級管理與報表。
- 產品功能展示與服務說明。

不採用的部分：

- 不將 Stripe 的靛藍漸層直接套用到全站。
- 不讓裝飾性漸層影響學習資訊的閱讀。

### 3.5 Notion

**設計印象：** 知識整理、親和、功能完整。

參考文件呈現的特色：

- 深藍色主視覺區域。
- 使用多種柔和色彩區分功能。
- 標題與內文具有清楚的字級層次。
- 使用圓角卡片呈現不同功能。
- 透過工作區畫面展示實際產品。
- 以不同色彩輔助知識與功能分類。

碼上學的應用：

- 課程、教材與題庫分類。
- 學習資源與知識整理。
- 學生個人學習空間。
- 教師課程與班級管理功能。

不採用的部分：

- 不讓大量彩色卡片造成畫面雜亂。
- 不直接複製 Notion 的紫色主按鈕或品牌圖案。

## 5. 碼上學的整合設計策略

### 5.1 品牌定位

採用：

**Luxury-Inspired Premium EdTech**

結合精品品牌的視覺克制、科技產品的精準介面，以及教育平台的清楚易讀。

設計目標：

- 高級但不疏離。
- 科技感但不冰冷。
- 有視覺特色但不影響學習。
- 專業但適合學生與教師使用。
- 讓使用者能快速理解平台功能。

### 5.2 五個品牌的借鑑比例

以下為設計方向建議，不是品牌素材或版面複製比例。

| 參考來源 | 建議借鑑方向 |
| --- | --- |
| Apple | 留白、產品展示、資訊層級 |
| Nike | 大型主視覺、標題張力 |
| Linear | 專業介面、細節與資訊密度 |
| Stripe | 資料視覺化、產品展示 |
| Notion | 知識分類、柔和功能區塊 |

### 5.4 頁面應用方向

| 頁面 | 設計重點 |
| --- | --- |
| 品牌首頁 | 大型主視覺、留白、品牌故事 |
| 登入與註冊 | 簡潔、可信任、操作清楚 |
| 學生端 | 學習進度、課程、題庫與紀錄 |
| 教師端 | 班級管理、作業、考試與報表 |
| AI 助教 | 對話層級、分階段提示、柔和玻璃效果 |
| 遊戲學習 | 清楚規則、適度色彩、明確回饋 |

## 6. 需要避免的設計問題

1. 過度使用卡片，讓整個網站變得零碎。
2. 每個區塊都使用玻璃效果，造成視覺疲勞。
3. 大量使用紫藍漸層，失去品牌原有色彩辨識度。
4. 過度圓潤的按鈕與元件，降低專業感。
5. 使用發光邊框、過度陰影等裝飾，讓介面顯得廉價。
6. 為了追求高級感而犧牲文字可讀性。
7. 為了追求科技感而讓學習流程變得複雜。
8. 複製其他品牌的標誌、商標、特殊圖案或獨特版面。

## 8. 最終結論

碼上學不應成為 Apple、Nike、Linear、Stripe 或 Notion 的仿製品。

應保留自身的教育科技定位與原有品牌識別，從 Apple 學習留白與產品展示、從 Nike 學習視覺張力、從 Linear 學習專業介面、從 Stripe 學習資料呈現、從 Notion 學習知識分類。

最終建立一套具有碼上學自身特色的設計系統：

**高級、簡潔、專業、易讀，並以學習體驗為核心。**
