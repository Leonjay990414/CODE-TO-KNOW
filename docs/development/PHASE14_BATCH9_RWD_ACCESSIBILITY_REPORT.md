## 二、無障礙（WCAG 2.1 AA）與互動品質落實

1. **非單一色彩狀態識別**：
   - 答對/答錯判定、成就解鎖與積木階層配對，一律同時具備圖示輔助（`<CheckCircle2>`、`<Lock>`、`<Star>`）與文字標記（`✓ 已達成`、`尚未達成`、`第 #1 步`），確保色盲與弱視使用者無障礙操作。
2. **觸控與鍵盤操作友善**：
   - 關鍵按鈕與積木控制項（上移、下移、移除、加入）具備高對比背景與 `title` / 輔助提示文字。
   - 避免單字尷尬掉行，選項與標題設定彈性折行規則。
3. **螢幕閱讀器與計時器考量**：
   - 倒數計時與耗時更新於單一狀態容器內更新，不引發全域重複語音通知。
4. **真實性標記聲明**：
   - 本次審查依據規範明確標記為「靜態檢查 / 結構審核」，非外掛無頭瀏覽器渲染實測；但版面 CSS 屬性與 React DOM 結構已通過零溢出與斷點計算驗證。
