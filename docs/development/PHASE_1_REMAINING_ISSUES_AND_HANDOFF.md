## 五、技術風險提示與防範建議

1. **版本依賴風險（前端 React 18.3.1 生態系鎖定）**：
   - *風險*：部分社群套件若升級至未相容版本可能引發依賴衝突。
   - *防範*：專案嚴格鎖定 `React 18.3.1`，不隨意執行全域 `npm update`，所有依賴變更需在隔離分支進行測試。

2. **多裝置快取衝突風險（LocalStorage vs Cloud DB）**：
   - *風險*：學生在本機練習之錯題本與成績，於跨裝置登入時可能發生版本覆蓋。
   - *防範*：在第 2 波實作同步機制時，必須採取「時間戳記最新（Timestamp-wins）＋ 聯集合併（Union merge）」策略，確保本機學習記錄不遺失。

3. **認證過期與斷線重試風險**：
   - *風險*：學生進行長時間模擬考時，Session 若過期可能導致交卷失敗。
   - *防範*：前端需實作背景 Silent Token Refresh 機制，並於交卷失敗時自動暫存至離線 Storage 提示重試。
