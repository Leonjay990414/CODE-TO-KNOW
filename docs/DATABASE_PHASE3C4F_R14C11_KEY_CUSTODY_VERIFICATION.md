## 三、重大保管缺口判定與落實清單 (Action Items for Project Lead)

> [!WARNING]
> **重大保管缺口聲明**：  
> 儘管本機加解密工具與語法已 100% 驗證通過，但在**實體金鑰保管設施**層面，目前專案尚未正式完成「企業級密碼庫註冊」與「離線第二份實體備份放置」。  
> 依據審查規範，**此項目不得判定為無缺口（NOT GAP-FREE）**，專案負責人必須在簽發正式備份執行命令前完成下列動作：

### 專案負責人必須完成之落實清單：
- [ ] **ACT-K01**：在專案負責人個人的企業級密碼庫（例如 1Password / Bitwarden / KeePass，需具備 2FA）中，建立名為 `CODE_TO_KNOW_PROD_BACKUP_MASTER_KEY` 的安全機密項目。
- [ ] **ACT-K02**：執行 `node scripts/database/backup-crypto.cjs genkey` 產生 64 位元 Hex 金鑰，**立即存入上述密碼庫，絕不存入任何剪貼簿共用軟體或雲端筆記本**。
- [ ] **ACT-K03**：將該金鑰打印或抄寫於「實體緊急復原卡」，置於密封信封並存入實體防火防潮保險箱中（建立獨立的第二份離線備份）。
- [ ] **ACT-K04**：在本機建立安全金鑰檔，並透過 PowerShell 執行 ACL 鎖定：
  ```powershell
  icacls "C:\Users\user\Documents\CODE-TO-KNOW_SECRETS\keys\c2k_backup_master.key" /inheritance:r /grant:r "$($env:USERNAME):(R)"
  ```
