歡迎使用「碼上學」（CODE TO KNOW）。本平台致力於打造安全、可信賴的 AI 智慧教育科技環境。為了落實個人資料保護法規（包括個人資料保護法及相關主管機關規範）並向您清楚說明本平台如何蒐集、處理、利用及保護您的個人資料，特訂定本隱私權保護政策（以下簡稱「本政策」）。

請您在註冊、登入或使用本平台各項服務前，務必詳閱本政策內容。若您為未成年人，請與您的法定代理人（如父母或監護人）共同閱讀並取得其同意。

## 一、平台與政策適用範圍

1. **適用範圍**：本政策適用於本平台所提供之官方網站（含展示預覽站）、會員系統、學科題庫、術科程式實作練習、AI 智慧助教導航、教師教學管理後台及相關衍生數位服務。
2. **不適用範圍**：本政策不適用於本平台以外由第三方所獨立經營之網站、外部連結或服務（例如第三方線上資源、外部教材來源等）。當您點擊該等連結前往第三方網站時，其個人資料之蒐集與保護應適用該第三方網站個別之隱私權規範。

## 二、我們蒐集的個人資料類型

本平台僅於提供教育與學習服務之必要範圍內，蒐集以下類別之個人資料：

1. **基本帳號資料**：
   - 註冊與登入時提供之電子郵件地址（Email）、使用者顯示名稱（Display Name）、自訂密碼（後端以 bcrypt 單向雜湊加鹽加密保存，絕無明文儲存）。
2. **身分與角色資料**：
   - 使用者角色屬性（如一般學員 `STUDENT`、認證教師 `TEACHER`、管理員 `ADMIN`）。
   - 教師申請時所填寫之審核資訊（姓名、服務機構／學校、專業領域或證明連結）。
3. **學習歷程與互動資料**：
   - 學科測驗紀錄（題組作答選項、交卷時間、答對率與成績計算）。
   - 術科實作進度（程式碼撰寫與預覽狀態、本地作業暫存）。
   - 收藏題目、錯題本紀錄、單元學習進度與學習時間統計。
4. **系統與技術使用資料**：
   - 連線設備之 IP 位址、瀏覽器類型與版本、裝置螢幕解析度、連線時間戳記。
   - 伺服器端操作稽核日誌（Audit Log，包含重要權限變更、密碼重設與登入驗證事件；系統嚴格執行機敏脫敏遮蔽處理）。

我們基於以下教育科技與服務運作之正當合法目的，蒐集並利用您的個人資料：

## 四、資料保存位置、儲存架構與保存期限

### 1. 資料實際儲存架構現況說明（透明揭露）
本平台目前處於工程推進與安全驗證階段，資料之實體處理區分如下：
- **本機展示與預覽模式（Demo Mode / GitHub Pages）**：
  - 於公開靜態預覽站中，不建立遠端資料庫連線。示範帳號（`STUDENT`、`TEACHER`）與模擬題庫暫存於瀏覽器之 `LocalStorage` 或記憶體中，關閉或清理瀏覽器即可重置。
- **後端 API 與本機隔離資料庫環境**：
  - 正式帳號與核心資料模型（Prisma 36 業務模型）儲存於具備安全存取控制之 PostgreSQL 資料庫。
  - 目前所有正式備份均採用高強度 AES-256-GCM 密碼學加密儲存（C2KB 規格），金鑰與密文嚴格實體分離。
- **雲端正式託管庫（Supabase / Render）**：
  - 目前生產資料庫切換與遠端服務處於待正式安全割接驗證階段（AUTH-03 BLOCKED 隔離狀態），尚未開放對外寫入真實大量生產數據。

### 2. 資料保存期限
- **帳號存在期間**：在您的帳號維持有效之期間內，我們將持續保存您的帳號與學習紀錄，以利您跨階段持續學習。
- **操作稽核紀錄（Audit Logs）**：基於資安追蹤與事故防範，系統稽核日誌依法定或資安慣例保存特定期間（建議為 6 個月至 1 年，依正式營運政策為準），期滿定期覆寫或歸檔。
- **備份封存**：加密備份檔案依照備份輪替政策進行定期歸檔與安全銷毀。

## 五、第三方服務與資料跨境傳輸

本平台對第三方工具與外部傳輸採取嚴格最小化原則：

1. **無商業廣告與第三方行銷追蹤**：本平台目前**未嵌入**任何第三方商業廣告追蹤代碼（如 Google AdSense、Facebook Pixel 等），亦不將您的個資販售或提供給行銷業者。
2. **外部字型資源**：平台前端引用 Google Fonts（Noto Sans TC、Inter、JetBrains Mono）以確保跨裝置字體排版一致性，連線僅傳輸瀏覽器必要標頭，不包含會員帳號資訊。
3. **電子郵件發信服務（待確認）**：目前後端發信模組設定為開發模擬（`ConsoleEmailProvider`）與未啟用狀態（`DisabledEmailProvider`），尚未串接第三方商業郵件供應商（如 SendGrid、AWS SES 或 Resend）。正式上線前將補正對應服務商與傳輸規範。
4. **大語言模型 API（待確認）**：AI 智慧導師目前以前端本地教學規則與示範資料庫運作，尚未直接向外部大語言模型（如 Google Gemini API、Vertex AI）傳輸使用者即時對話資料。未來串接時將另行公告並嚴格執行脫敏處理。

## 六、帳號安全與技術防護措施

為維護資料之完整性、機密性及可用性，本平台實施以下多重安全機制：

1. **傳輸加密**：全站強制啟用 HTTPS（TLS 1.2+）加密傳輸，防止中間人竊聽或竄改。
2. **憑證與工作階段保護**：
   - 採用 HTTP-only、Secure、SameSite 限制之工作階段 Cookie（Session Cookie），防止 Cross-Site Scripting (XSS) 竊取憑證。
   - 全面部署 CSRF Token 雙重驗證中介軟體，防範跨站請求偽造。
3. **密碼強度與單向雜湊**：使用者密碼強制要求符合長度與複雜度驗證，並使用 bcrypt 進行單向雜湊加密加鹽儲存。
4. **機敏資訊脫敏日誌**：伺服器端錯誤日誌與稽核紀錄內建自動遮蔽器（Redaction），密碼、Token、金鑰與個資絕不以明文寫入日誌。
5. **最小權限原則（RBAC）**：系統採角色權限控制與伺服器端物件屬主驗證（IDOR 防護），不可相信前端傳入之角色身分。

## 七、Cookie 與瀏覽器儲存技術之實際用途

本平台使用瀏覽器儲存技術僅為維持核心教學功能，絕不作惡意追蹤：

| 儲存機制 | 儲存鍵值／名稱範例 | 主要用途 | 生命週期 |
| :--- | :--- | :--- | :--- |
| **HTTP Cookie** | `c2k_session`、`c2k_csrf_token` | 維持登入驗證、身分識別與 CSRF 資安防護 | 瀏覽器關閉或登出時過期 |
| **LocalStorage** | `ctk_demo_user` | 於靜態展示站記錄訪客切換之角色身份 | 使用者手動清理前有效 |
| **LocalStorage** | `ctk_code_editor_autosave_*` | 實作程式編輯器本地即時自動存檔，防作答遺失 | 留存於使用者本機端 |
| **SessionStorage** | `intended_route` | 記錄登入前預計造訪之受保護頁面，登入後自動導回 | 分頁關閉後自動清除 |
