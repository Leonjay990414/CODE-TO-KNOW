## 二、Windows／macOS 桌面端技術選型評估（P20-OPS-011）

針對學校電腦教室封閉網路、專業監考與離線練習情境，針對三種主流桌面端技術方案進行客觀對照：

| 評估維度 | 方案 A：Tauri 2.0 (Rust + Webview) | 方案 B：Electron (Node + Chromium) | 方案 C：Flutter Desktop |
|---|---|---|---|
| **安裝檔大小** | **極小（約 10 ~ 15 MB）** | 較大（約 90 ~ 130 MB） | 中等（約 30 ~ 45 MB） |
| **記憶體佔用** | **低（~40 MB RAM）** | 較高（~150 MB RAM） | 中等（~70 MB RAM） |
| **程式碼復用率** | **100% 復用現有 React 前端** | 100% 復用現有 React 前端 | 需以 Dart 重寫介面組件 |
| **底層安全防護** | Rust 原生記憶體安全、嚴格 IPC 授權 | 需注意 Node.js 遠端執行漏洞防護 | 依賴 Dart FFI 與平台通道 |
| **監考鎖定能力** | 支援 Kiosk Mode 全螢幕鎖定、切頁偵測 | 支援 Kiosk Mode 全螢幕鎖定 | 需額外撰寫原生外掛 |
| **綜合建議評級** | **第一優先（首選方案）** | 第二候選方案 | 不推薦作為桌面首選 |

### 結論與規劃
- **最佳推薦**：採用 **Tauri 2.0** 作為 CODE TO KNOW 桌面端封裝技術。可 100% 直接將現有 `frontend/dist/` 作為靜態資源載入，既有 460+ 項前端單元測試無痛相容，並透過 Rust 提供防作弊全螢幕檢定鎖定功能。
