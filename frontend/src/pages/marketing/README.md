# Marketing｜公開宣傳網站 (Level 1)

## 一、層級定位
- **架構層級**：第一層（Level 1）- 公開宣傳網站（Website）
- **主要對象**：未登入訪客、高中職學生、指導教師、學校行政人員、產學合作夥伴。
- **技術規範**：React + TypeScript + Vite 元件（`.tsx`），禁止擅自拆解為獨立 HTML 網站。

## 二、層級職責
1. **品牌形象展示**：傳達「碼上學，學無止境。Learn Beyond Limits.」之核心品牌精神與理念。
2. **產品與功能介紹**：展示學科題庫、術科實作、AI 輔助學習、雙軌教學平台等產品優勢。
3. **公開展示與範例**：提供成果示範（如網頁設計丙級術科展示 demo）、課綱與考科總覽。
4. **App 與入口指引**：提供 App 下載指引、社群連結、平台導覽與登入/註冊入口。

## 三、預計收納頁面清冊（待後續搬移階段執行）
- `HomePage.tsx`：首頁著陸頁（Hero、品牌故事、雙軌受眾展示、功能亮點）。
- `CertificationsPage.tsx`：公開檢定證照與考科分類目錄。
- `CertificationDetailPage.tsx`：證照詳細規範與課綱介紹。
- `WebDesignCDemoPage.tsx`：網頁設計丙級術科成果公開示範展示。

## 四、權限與存取控制
- **公開存取（Public）**：無須任何身分驗證，支援搜尋引擎索引（SEO）。
