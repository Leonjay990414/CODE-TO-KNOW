# Teacher｜教師教學後台 (Level 3)

## 一、層級定位
- **架構層級**：第三層（Level 3）- 教師教學後台（Web Pages - Educator Dashboard）
- **主要對象**：高中職專任教師、指導教練、補習班講師。
- **技術規範**：React + TypeScript + Vite 元件（`.tsx`）。

## 二、層級職責
1. **教學班級管理**：班級建立、邀請代碼管理、學生加入審核與名單維護。
2. **學生成效儀表板**：班級學科/術科測驗成效統計、弱點題目聚類分析、未交作業追蹤。
3. **任務與作業佈置**：指派學科練習卷、發布術科練習題組、設定繳交期限。
4. **教師認證狀態管理**：教師身分審核狀態追蹤、機構服務證明上傳與更新。

## 三、預計收納頁面清冊（待後續搬移階段執行）
- `TeacherDashboardPage.tsx`：教師教學管理中心主控台（整合班級、學生、指派任務與教學統計）。
- 未來規劃擴充子頁面（如班級詳細分析、考卷批改等）。

## 四、權限與存取控制
- **教師權限保護（Protected - Teacher/Admin）**：
  - 嚴格要求具備 `TEACHER` 或 `ADMIN` 角色。
  - 未登入或非教師角色直接存取將被 `ProtectedRoute` 攔截，並導向登入或申請教師認證介面。
