# Platform Admin｜平台管理後台 (Level 4)

## 一、層級定位
- **架構層級**：第四層（Level 4）- 平台管理後台（Web Pages - Platform Admin Console）
- **主要對象**：平台營運管理員、教務負責人、內容審核員。
- **技術規範**：React + TypeScript + Vite 元件（`.tsx`）。

## 二、層級職責
1. **教師資格審查**：審核教師申請名冊、檢視學校服務證明與電子信箱驗證。
2. **使用者帳號治理**：管理學生/教師帳號狀態（啟用、凍結、重設、角色指派）。
3. **教學班級治理**：全站班級總覽、違規班級處置、跨校班級統計。
4. **官方題庫管理引擎**：官方題庫來源登錄（勞動部/技檢中心）、題目匯入與結構化解析、學術科教材發布與版本控制。
5. **全站公告與營運政策**：系統全站公告發布、政策文件維護。

## 三、預計收納頁面清冊（待後續搬移階段執行）
- `AdminDashboardPage.tsx`：平台管理主控台（業務管理視圖：教師審查、帳號治理、班級監管）。
- `QuestionBankImportSystemPage.tsx`：官方證照題庫匯入與解析管理系統。

## 四、權限與隔離邊界
- **管理員身分保護（Protected - Admin Only）**：
  - 嚴格要求具備 `ADMIN` 或 `PLATFORM_ADMIN` 角色。
  - **重要架構邊界**：本層為「教育平台業務管理」，嚴格與第五層「系統維運與硬體監控（System Ops）」分離。本層不應涉及底層資料庫直接連線池管理、伺服器硬體負載等底層維運。
