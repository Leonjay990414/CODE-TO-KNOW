# CODE TO KNOW（碼上學）Prototype 功能真實性盤點清單 (Showcase Feature Inventory)

**版本**：v1.0 (Phase 6 正式展示交付版)  
**盤點目的**：全面界定 HTML Prototype 之功能邊界，供比賽展示者、評審及技術團隊精準了解「已實際運作」、「前端原型模擬」與「尚未串接」之功能分佈，落實誠信透明之教育科技原則。

---

## 一、功能分類準則說明

- **【A. 已實際運作】**：功能完全依賴前端原生程式碼（HTML5 / CSS3 / 原生 JavaScript DOM 操作）執行，不依賴後端即可在離線狀態下產生即時、準確且可重複驗證的真實結果。
- **【B. Prototype 模擬功能】**：具備完整的使用者互動歷程與狀態回饋，但運算資料源自前端預載之靜態標準範例或規則庫，尚未連接正式資料庫持久化儲存。展示時應明確說明為「原型交互演示」。
- **【C. 尚未串接或待開發】**：在介面上已提供完整按鈕、表單或彈窗視覺入口（點擊會提供規範性 Toast 提示或指引），但核心底層（如遠端 AI LLM API、雲端身分認證、正式題庫資料庫）屬於正式全端架構範疇，於 Prototype 階段尚未連動。

## 三、展示注意事項總結

1. **實操亮點優先展示**：代碼工作台（即時輸入即時預覽）、術科五大題組切換、證照中心 150ms 防抖搜尋、模擬考淡入結算彈窗，這些均為 **A 類完全實際運作功能**，可鼓勵評審或觀眾現場隨意操作。
2. **誠實說明 AI 助教定位**：向評審介紹 AI 助教時，著重講解「4 階思考鷹架（Scaffolding）」如何避免學生直接抄答案，並誠實說明 Prototype 現階段以示範提示流程為主，後端正式版已規劃串接正式 LLM API。
3. **強調官方資料嚴謹性**：說明網頁設計丙級 100% 依循勞動部官方五大題組規範，其餘五大證照清楚標示 COMING SOON，展現踏實、可信賴的產品工程水準。
